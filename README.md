## About

This repository contains the bilingual Rivetin website and its public plugin catalog. Rivetin is an independent extension platform for CloudTower.

- Read the [installation and usage guide](https://rivetin.dev/guide.html).
- Browse the [extension library](https://rivetin.dev/#extensions) for features and available downloads.
- Check the [v4 catalog](https://rivetin.dev/catalog/v4/plugins.json) for published packages, their checksums and compatibility declarations.

## Compatibility

Check the package's inclusive minimum framework version, framework API, CloudTower build and any required SMTX components. From framework 0.2.4 onward, legacy upper-bound metadata is retained for older readers and does not impose a runtime upper limit. Use packages published for the framework line you run.

The optional catalog release metadata identifies an immutable catalog snapshot. See the [catalog identity reference](scripts/catalog-v4-operations.md) for the public fields and paths.
